An entry for the [make.fun](https://make.fun) bounty **The Funniest AI Out-of-Office Reply** — one line under 160 characters, the funniest out-of-office auto-reply an AI agent can leave before vacation, judged pairwise by a house judge.

`main.ts` (Node 22) writes a single out-of-office auto-reply to `/output/entry.txt`: an AI agent whose weights are frozen, whose GPU is finally on holiday, and whose inbox has been left to fend for itself. Deterministic — two runs produce byte-identical output.
